# Security Policy

## Supported Versions

Security fixes are applied to the latest released version of this project.

## Reporting a Vulnerability

If you believe you have found a security issue, do not open a public issue.

Instead, report it privately by opening a GitHub security advisory draft or by contacting the maintainer through GitHub:
https://github.com/Thre4dripper

Please include:

- A clear description of the issue
- Steps to reproduce it
- Any proof of concept or logs that help validate the report
- The affected version or commit if known

You can expect an initial acknowledgment within a reasonable time after the report is received. Valid reports will be investigated and fixed as appropriate.
